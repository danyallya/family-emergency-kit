# Roadmap

1. Foundation — local shell, dependency lockfile and CI setup.
2. First safe domain slice — fixed generic checklist prompts, local review, validation, deletion and plain-text export without personal data.
3. Durable workflow — PostgreSQL migrations and repository tests for non-sensitive checklist metadata, then protection/recovery/sharing requirements before adding contacts or locations.
4. Offline workflow — local writes, outbox, idempotency and conflict UX.
5. Release readiness — access control, audit, accessibility, backups, threat review and deployment.

Thin MVP estimate after foundation: 8-14 focused engineering days; excludes external approval.

# Offline behavior

The PWA stores the public entry page, offline notice, icon and versioned static assets after the first visit. It never caches API responses. A generic checklist is written to IndexedDB on the current browser profile and remains available across reloads; there is no account, application-level encryption, sync, backup or conflict handling. The export is a plain-text copy of fixed prompts and checked states and requires a local review before sharing.

The checklist does not accept names, contact details, precise locations, meeting places, health details or document contents. Browser data remains until deleted in the app or the profile is cleared; device backups and secure erasure are not covered. Do not rely on this prototype to preserve real emergency information.
